# bead 0.1: out, and it updates itself

## Problem Statement
How might we turn bead from "my repo that installs cleanly" into something a
stranger finds, trusts, installs, and keeps up to date?

## Recommended Direction
A v0.1 public release, in order:

1. **Audit** — history scanned (126 commits): no secrets, real MACs or IDs.
   Only a LAN IP in an old comment (already gone from HEAD) and the author
   email on every commit. Decision: keep both; no history rewrite.
2. **Release kit** — `VERSION` + `bead --version`; `CHANGELOG.md` from
   Conventional Commits (0.1 notes hand-edited); `packaging/PKGBUILD`
   (`bead-shell-git`) installing to `/usr`, proven in the friend test.
3. **`bead update`** — git checkout: fetch tags, if newer run the doctor and
   `make install` (with its rollback), then an island "what's new" toast.
   AUR install: point to `paru -Syu`. A daily check shows "update available"
   in Settings → System.
4. **README** — screenshots on bead's own wallpapers, a 15-second clip,
   three install lines at the top, version and CI badges.
5. **`bead uninstall`** — files, the `require("bead")` line; settings kept
   unless `--purge`.
6. **CI** — GitHub Actions in `archlinux:latest`: `make test`, the friend
   test (inner script shared with podman), and a PKGBUILD install + doctor.

## Key Assumptions to Validate
- [ ] bead runs from `/usr/share/bead` — PKGBUILD install in the friend test
- [ ] Most early installs are git checkouts — `bead update` targets git first
- [ ] Commit subjects make a readable changelog — generate 0.1, read it
- [ ] The Arch container works on GitHub runners within free minutes

## MVP Scope
All six. Making the repo public, pushing to the AUR and publishing the
GitHub release stay with the owner.

## Not Doing (and Why)
- `bead try` — hiding someone else's bar depends on their setup
- Rewriting history — the audit found no need
- Package caching in CI — a later speed-up
- Publishing anything — outward-facing; prepared, not pressed

## Open Questions
- AUR name: `bead-shell-git` unless the owner prefers another.
